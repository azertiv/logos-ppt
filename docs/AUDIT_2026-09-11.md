# Revue Neurow.Pictos — 11 septembre 2026

## Résultat et portée

La revue a porté sur le complément web, son import ZIP, le stockage, la recherche locale, les appels IA, l’insertion Office, le manifeste, la compilation statique et le nouveau compagnon Codex. Les corrections sont préparées localement ; elles ne sont pas publiées. Une revue ne peut pas certifier l’absence absolue de bugs. Les preuves ci-dessous distinguent les essais automatisés, le navigateur, l’appel réel Codex et les vérifications qui restent propres au PC professionnel.

## Codex : développement et essai réel

Le compagnon Node démarre le processus officiel `codex app-server`, avec une connexion ChatGPT propre au compagnon. Il découvre les modèles et lit les limites directement auprès de Codex. Il accepte uniquement les deux opérations bornées d’expansion et de classement. Les entrées sont validées, les identifiants du classement doivent appartenir aux candidats et aucune commande arbitraire n’est exposée au complément.

Le serveur écoute uniquement sur l’interface locale ; les requêtes sont protégées par un code aléatoire de session et une vérification de l’origine. Les clés API de l’environnement sont exclues du processus enfant. Les recherches utilisent des fils éphémères, sans outils de commande ni navigation web ; les demandes d’outils/permissions sont refusées. Les erreurs et annulations ne déclenchent aucun repli vers l’API payante.

**Essai réel réussi sur macOS**, avec le compte connecté par l’utilisateur : deux opérations `gpt-5.6-luna` sur « Supplier Questionnaire », environ **9,13 s** au total. L’expansion a proposé notamment `questionnaire form`, `clipboard`, `checklist`, `supplier`, `vendor` ; le classement a retourné Checklist puis Supplier et écarté Dog. Il s’agit d’un essai sur des exemples non confidentiels, pas d’un banc de mesure de latence ni d’une validation de la bibliothèque d’entreprise. L’instance macOS utilise Codex 0.153.4 ; le paquet Windows contient le runtime officiel 0.154.0, qui reste à essayer sur Windows.

## Raccourci et insertion

L’action capture le texte et la diapositive avant d’ouvrir le volet, affiche la recherche, attend le classement et insère le premier résultat. Elle ajoute un pictogramme sans supprimer le texte sélectionné. Elle refuse une seconde invocation simultanée et vérifie que la recherche, la bibliothèque et la diapositive n’ont pas changé avant l’insertion. Ces protections sont couvertes par des tests avec Office simulé.

L’ouverture du volet fermé utilise le moteur partagé Microsoft. Le chargement lors de la réouverture de la présentation est une option explicite. La compatibilité du raccourci et ses conflits avec les commandes natives doivent être validés sur le poste réel ; voir le protocole Windows.

## Preuves et limites

La suite comprend **29 tests automatisés** : frontières HTTP et authentification, quota et modèles sans inférence, réponses structurées, refus d’outils, arrêt/annulation/reprise, séparation API/Codex, déduplication, délai, cache, ZIP, fenêtre de grille et protection de l’insertion. Le site statique et l’archive portable font également l’objet de contrôles de contenu ; les sommes de contrôle des exécutables officiels et de l’archive sont fournies.

Dans le navigateur, 1 740 SVG synthétiques ont été importés, restaurés depuis le stockage, parcourus, filtrés et affichés à trois et six colonnes. Ils sont volontairement simples : ces essais ne démontrent ni un niveau de FPS ni une consommation CPU/mémoire sur les SVG de l’entreprise. Aucun temps d’import fiable n’est annoncé : l’outil d’automatisation a lui-même connu une attente anormale pendant le choix de fichier.

**Restent à vérifier sur le PC professionnel** : exécution des binaires portables et autorisation du réseau local, connexion depuis le moteur web de PowerPoint, insertion SVG native et remplacement de forme, raccourci volet ouvert/fermé, chargement à la réouverture, performances avec les vrais fichiers. La clé API existante est conservée, mais son fonctionnement avec Luna n’a pas fait l’objet d’un appel réel pendant cette revue. Ni Microsoft Marketplace ni GitHub Pages n’ont été publiés ici.
